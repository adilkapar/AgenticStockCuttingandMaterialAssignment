SLIDE 3 — Challenges, Solution, Benefits, Internal Comments Same title bar and divider as slide 2. 2×2 quad layout — each quadrant has a teal uppercase bold section header followed by body text:

TOP-LEFT — "CHALLENGES AND BUSINESS DRIVERS": "Mill Products processors universally face: (1) Parameter-intensive matching — each raw material unit is characterized by 5-15+ physical/chemical parameters that must match order specifications exactly or within tolerance (Steel: 13 parameters including quality, thickness, width, coating, roughness, passivation; Paper: 8+ parameters including grade, basis weight, caliper, brightness; Aluminum: 10+ parameters including alloy, temper, thickness, surface finish). (2) Procurement before demand — raw materials must be ordered weeks to months before customer orders are confirmed, creating structural supply-demand mismatch. (3) Manual planning dependency — cutting plans created by experienced planners using spreadsheets, producing 8-20% trim waste versus 2-5% achievable with optimization. (4) Multiple conflicting objectives — minimize trim waste vs. minimize tardy orders vs. minimize idle stock vs. maximize throughput. (5) Dynamic disruptions — rush orders, supplier delays, machine issues, forecast errors cause daily plan revisions. (6) SAP gap — standard PP/MRP cannot solve combinatorial cutting pattern and multi-parameter assignment optimization."

TOP-RIGHT — "SOLUTION": "An industry-configurable Agentic AI system built on SAP BTP: (1) SAP Joule Orchestrator — natural language interface in SAP Fiori, LLM reasoning (ReAct pattern), industry-agnostic orchestration logic that applies identically to steel, paper, aluminum, or any mill product. (2) Order Agent — reads SAP S/4HANA SD, configurable N-parameter matching per industry vertical. (3) Stock Agent — reads SAP S/4HANA MM, handles coils, rolls, sheets, and reels with industry-specific material master data. (4) MCP Optimization Server (Python/OR-Tools) — 5 configurable tools: N-parameter feasibility network builder with connected component decomposition, 1D/2D cutting pattern solver (slitting, sheeting, cross-cutting, die-cutting), multi-objective MILP assignment optimizer with configurable weights, plan evaluator, and purchase recommender. (5) SAP Integration — reads via CDS views/OData, writes via BAPI (reservations MB21, production orders CO01, purchase requisitions ME51N), reacts via SAP Event Mesh. Same engine, industry-specific configuration."

BOTTOM-LEFT — "BENEFITS": "Trim/scrap reduction of 50-75% across all mill product types (from 8-20% manual to 2-5% optimized). Planning time reduction from hours to less than 15 seconds for a full planning run. Order fulfillment improvement to 90-95%+ with automatic gap identification. Idle stock reduction of 20-40% through proactive material-to-order matching. Industry-specific ROI examples: Steel (500 tons/month at EUR 800/ton) = EUR 28,000/month savings; Paper (1,000 tons/month at EUR 600/ton) = EUR 42,000/month savings; Aluminum (200 tons/month at EUR 2,500/ton) = EUR 35,000/month savings — all from trim reduction alone. Additional benefits: elimination of person-dependency, full explainability of every decision, event-driven proactive re-planning, what-if scenario exploration, every plan immediately actionable as SAP shop orders, standardized process across plants and shifts, and same system serving multiple industry verticals through configuration."

BOTTOM-RIGHT — "INTERNAL COMMENTS": "The cutting optimization problem is fundamentally the same whether you cut steel coils, paper rolls, or aluminum sheets. What changes is the parameter set and the machine constraints. The AI reasoning and SAP integration are universal. One platform, many industries." — Solution Architect

"In paper converting, we used to waste 12% of every parent roll. The agentic system brought us down to 4%. The same logic applies to steel service centers, aluminum converters — anyone doing cut-to-order processing." — Production Manager, Paper Converting
